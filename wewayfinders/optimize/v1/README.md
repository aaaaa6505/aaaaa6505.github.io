# 天路尋航 We Wayfinders — 單頁教材閱讀版 v2.4

## 開啟方式
完整解壓縮後，直接以 Chrome、Edge 或 Safari 開啟 `index.html`；無須安裝或網路伺服器。

## 改版內容
- 取消原本的五個頁籤切換機制，**課前預備 → 暖身活動 → 故事時間 → 影片 → 回應活動** 全部依序出現在同一頁。
- 將目錄精簡為 **課前、暖身、故事、影片、回應**，以五欄等寬按鈕呈現；320px 手機也不需要橫向捲動。
- 點選目錄是同頁錨點跳轉（網址會顯示 `#section-...`）；不會隱藏或載入其他區塊。
- 保留「回應活動」四種年齡層活動的跳轉捷徑。
- 保留標題下方可見的 A−／滑桿／A＋ 字級控制（16–24px），並記住使用者選擇。
- 沿用淺色導航列、品牌藍與金色提示、18px 預設教材正文。
- 全部使用離線 HTML、CSS、JavaScript，未使用外部 CDN。

## 教材來源與限制
- 教案文字取自使用者提供的原始 HTML，以及先前 v2.3 教師討論版；沒有改寫原教案段落。
- 原始 HTML 有顯示 PDF、PPTX、影片的附件名稱，但壓縮檔不含這些實體教材資源，附件無法直接下載或播放。
- 部分網站導覽連結指向天路尋航正式站，需網路連線才能開啟。

## 檔案結構
- `index.html`：單頁教材、五個錨點段落
- `styles.css`：品牌樣式、桌機／手機 RWD、單頁閱讀目錄
- `app.js`：字級設定、導覽選單互動
- `assets/logo-blue.png`、`assets/logo-white.png`：品牌 Logo

## v2.5 目錄文字響應式調整

- 電腦版（視窗寬度大於 700px）顯示完整目錄：課前預備、暖身活動、故事時間、影片、回應活動。
- 手機版（700px 以下）顯示精簡目錄：課前、暖身、故事、影片、回應。
- 仍為單頁連續教材，點目錄僅跳至對應錨點，沒有頁籤切換。
- 保留閱讀字級調整與原始教材內容。
