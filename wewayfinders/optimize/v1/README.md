# 天路尋航 We Wayfinders｜Canvas 設計理念融合版 v3

## 開啟方式
將 ZIP **全部解壓縮**，雙擊 `index.html`（推薦 Chrome、Edge、Safari）。此套件沒有外部套件依賴，可離線預覽。

## 與 v2.5 相比
- **桌機：** 參考 Canvas LMS 教材模組理念，新增左側固定的「本課章節」導覽，顯示完整名稱及活動時間。
- **手機：** 仍保留同一列「課前／暖身／故事／影片／回應」，不需左右滑動。
- **內容：** 五個完整教材區塊依順序在同一頁閱讀；所有區塊預設展開，可選擇個別收合。
- **教學結構：** 清楚的 01–05 模組標題，統一教材卡片、分齡活動與附件樣式。
- **閱讀設定：** 課程標題下持續顯示 16–24px 字級調整，另可選擇行距 1.6／1.8／2.0 與暖白閱讀背景。
- **定位：** 桌機導覽反映目前所在章節；頁面向下捲動後提供返回頁首按鈕。
- **設計：** 延用天路尋航專屬品牌藍 `#479EC6`、功能藍 `#246D8C` 與暖金色 `#E8B84B`。

## 教材內容與限制
- 教材文字與 v2.5 一致，源自提供的《亞伯拉罕之約（一）》HTML。
- 附件名稱原樣保留，但 **PDF、PPTX、影片原始檔不包含在壓縮檔內**，因此附件不是可操作的下載連結。
- 外部選單連結指向天路尋航正式網站，需連線才能開啟。
- 此版參考 Canvas LMS 的 **教材模組化、階層導覽、一致性及閱讀輔助理念**，並非 Canvas 官方外觀或 UI 元件複製品。
- 目前僅為可操作的前端設計預覽，尚未串接正式網站後端。

## 主要檔案
- `index.html`: 課程內容與結構
- `styles.css`: 品牌色票、桌機／手機排版、教材卡片
- `app.js`: 字級、行距、背景設定、模組收合、錨點定位
- `assets/logo-blue.png` 和 `assets/logo-white.png`: 品牌資產
